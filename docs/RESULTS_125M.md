# 125M × 2.5B FineWeb results

All 20 listed runs reached the 2.5B evaluation and saved the verified final and 2500M checkpoints.
Each run used 16 sequences per micro-batch, 16 accumulation steps, sequence length 512 and a 250M-token count prefix.
`plain` uses the same base width and depth. `plain_eq_weights` uses the preflight-matched total parameter count.
Prefix-derived buckets estimate full-corpus counts. `pc_0` covers approximately 0–9, `pc_2` 10–99, `pc_3` 100–999, and `pc_4` 1,000+. The prefix leaves `pc_1` unresolved.
Training throughput includes compilation, milestone evaluation and milestone checkpoint writes. Inference timing measures model-only whole-sequence forward passes with fixed routing inputs.
