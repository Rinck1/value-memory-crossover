## Caveats that must stay in the captions

- **Fig. 1:** the 1000+ bucket is not consistently pair-favoured in these runs,
  and $V=1{,}500$ is an exception in the 100–999 bucket.  Do not describe the
  crossover as a sharp universal threshold; call it a range and report the
  bucket-level exceptions.
- **Fig. 3b:** the full fit including $d=128$ is non-monotone
  ($\alpha=-0.94$, $R^2=0.46$); the $d=128$ estimate is not identified.  Only
  the $d=16$–$64$ sublinear trend ($\alpha\approx0.32$) should be quoted as a
  scaling result.
- **Fig. 4:** the equal-weight plain model ($w=88$) has the best loss at
  $2.2\times$ the active FLOPs.  U123 wins at equal active FLOPs, not at equal
  weights; U1 is the Pareto-efficient variant on latency.
- **Fig. 5:** the held-out prediction is the strongest evidence in the paper;
  keep the preregistration text and the break thresholds in the appendix.
- **Fig. 6:** the 0 bucket receives no training signal and stays near
  $0.3$–$0.4$; the learned curve should not be over-interpreted as a
  rediscovery of the threshold.
- **Fig. 7:** 30M tokens, single seed: a directional bridge, not the 125M
  result.  The U123/CTRL_hs arms are not yet in this figure; add them when the
  full-vocabulary upgrade run is done.
